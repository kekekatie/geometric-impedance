# Gate test: is the non-Galois part of perpendicular space inert?

Set up in `TILING_CONFOUND.md`. The Z⁴ cyclotomic family matches perpendicular
dimension but the 10-fold member is not a tiling. The Z^n family tiles properly at
all three folds but appears to vary perpendicular dimension. The hope was that the
appearance was misleading.

Diagonalising the negacyclic shift (rotation by π/n in parallel space) shows
perpendicular space is never one block. It splits by whether the eigenvalue is a
primitive 2n-th root of unity:

| | Galois-conjugate plane | remainder |
|---|---|---|
| 8-fold (Z⁴) | ζ₈³, ζ₈⁵ | — |
| 10-fold (Z⁵) | ζ₁₀³, ζ₁₀⁷ | ζ₁₀⁵ = −1, one real direction |
| 12-fold (Z⁶) | ζ₁₂⁵, ζ₁₂⁷ | ζ₁₂³, ζ₁₂⁹ = ±i, a hidden four-fold plane |

If the remainder were inert, all three would carry a 2-dimensional Galois address,
the Z^n family would be matched on the quantity that matters, and it would be strictly
better than the Z⁴ construction — proper tilings, complete stars, matched dimension.

## Result: the remainder is NOT inert. Gate fails.

0.49, and adding it to the Galois plane improves the joint model (0.9630 vs 0.9446;
0.7636 vs 0.7307). It carries genuine address information and decays under disorder
much as the Galois plane does. Perpendicular dimension therefore differs in substance,
not only in bookkeeping.

**No contradiction with the earlier Penrose finding.** `discrete_vs_continuous.py`
showed the *discrete* lift-sum index to be inert (AUC 0.5398). That test grouped all
three continuous perpendicular coordinates together as "continuous". This is a finer
split, and the third *continuous* coordinate is what turns out to be live. Both
results stand.

## Control: 12-fold's weak channel is not boundary contamination

12-fold reads only ≈0.73 clean, against 0.98 for 8-fold, so the interior crop was
swept:

| active set | % of patch | Galois | remainder | shuffle |
|---|---|---|---|---|
| 700 | 46.2% | 0.7492 | 0.6312 | 0.5004 |
| 450 | 29.7% | 0.7479 | 0.5588 | 0.4267 |
| 300 | 19.8% | 0.5968 | 0.5883 | 0.4558 |
| 200 | 13.2% | 0.5587 | 0.5796 | 0.4925 |

Stable from 700 to 450 (0.7492 → 0.7479), so ≈0.75 is the bulk value. The fall at 300
and 200 is small-sample: at a 5% positive fraction those runs carry only 15 and 10
positives, below what the label supports. Not a boundary effect.

Worth noting that the same 12-fold family read far higher in the Z⁴ construction. The
construction matters a great deal, which is a further reason to settle the substrate
question before quoting any ordering.

## Do not read a family ordering off this table

At zero disorder these run 0.98 / 0.94 / 0.75 — silver > golden > platinum, which is
*not* the published order. That is not a refutation and not a replication: these are
three substrates with different perpendicular dimensions, so it is exactly the
comparison this project already rejected as unmatched. It is recorded here only so
nobody later mistakes it for evidence either way.

## The route out, now identified

Both families fail, but on complementary grounds, and there is a third construction
that fails on neither.

**Penrose is already a rank-4, perpendicular-dimension-2 cut-and-project.** The kernel
of Z⁵ → Z[ζ₅] is generated by (1,1,1,1,1), whose lift sum is 5. So lift sum *mod 5* is
a well-defined function of the rank-4 point, and the four pentagons are a congruence
class of the Z⁴ coordinates rather than an extra dimension. Verified directly: on a
5,192-vertex patch the lift sum takes exactly the values {1, 2, 3, 4} and equals its
own residue mod 5.

That generalises. For N = 8, 10, 12 the ring Z[ζ_N] is always rank 4, the star always
has N/2 directions, and the relation lattice has rank N/2 − 4 = 0, 1, 2. The window is
a union of pieces indexed by the resulting finite congruence group — **one** piece for
8-fold, **five** for 10-fold, and some determinable number for 12-fold.

A family built this way is matched on all four axes at once:

- rank 4 and perpendicular dimension 2, for all three
- the complete N-fold star, so the edge rule is basis-independent
- genuine rhombus tilings
- windows differing only in congruence structure

And the number of window pieces becomes a **mechanism variable forced by the
arithmetic** rather than imposed by hand. That is precisely the "lattice-commensurate
window fragmentation" lead, flagged in `LEADS.md` as the only fragmentation that does
not destroy the tiling, because it cuts along a lattice invariant instead of across
one. It arrived here on its own.
