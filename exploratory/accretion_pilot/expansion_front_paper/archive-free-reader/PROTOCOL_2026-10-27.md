# Verification protocol fixed before comparing results
27 October 2026. Post-review verification, not a preregistered experiment.
Source: a96c88b83a1d80f915dc29e0ffa193a6164f6e77.

Reader inputs: surviving decorated triangles with current physical coordinates; edge length and fixed projection directions; one common pre-fork physical origin representing lift zero; the common four-layer rank convention; fixed window normals/offsets; both hypothesis constraint sets in that gauge. No historical tile list, vertex lift labels, branch label, stream or answer-dependent alignment is supplied.

Reader reconstructs relative lifts separately on each present-edge connected component. It exhaustively inverts the component root's physical displacement modulo the all-ones kernel within |k_j-k_4| <= 128. Physical residual tolerance is 1e-7 edge units. Exactly one inverse is required. The all-ones ambiguity is fixed only when exactly one shift places the entire component within the supplied four consecutive layers; otherwise reconstruction fails. It does not silently omit out-of-slab vertices. This bounded numerical coordinate convention is part of the claim, not an unbounded exact-integer uniqueness theorem.

Constraint, area, and polygon-boundary agreement tolerance: 1e-10 absolute. Nonempty skin area threshold: 1e-12. Candidate intersection threshold: 1e-9, matching the original scored rule. Raw residuals retained. Geometry topology uses the original 6-decimal physical vertex keys; merged-coordinate consistency is checked. Region clipping uses the original [-50,50]^2 box and its half-plane convention; the implementation is separate.

Fresh process receives JSON on stdin, uses only the standard library, isolated interpreter -I -S and empty temporary working directory. After imports, an audit hook rejects file opens and network/subprocess access. Reference reconstruction/scoring stays in the controller. This is auditable separation, not an OS-level security sandbox.

Stage 1: first scored case, a scored B case, and the first positive roundoff-sized alternative-area case (deduplicated). Stage 2: only the original 49 scored continuations at step 44, from 20 of the 22 forks. Original 39 censored continuations remain visible and excluded by the original selection, not reclassified. Regenerate original worlds/streams because no saved full/skin checkpoints were found for these closure runs. Save reader-only payloads and analyst references separately in each case envelope; only payload is sent to reader. Check source scores, constraints, regions, intersections and lift labels outside the reader. Swap candidate order and apply the same nontrivial coordinate-gauge change to the geometry convention and hypotheses.
