# Accretion pilot v9 — substrate comparison: design & feasibility

**Design and feasibility only. No simulations were run.** This folder is a proposal
for Astra to review before any substrate-comparison pilot is built.

Central question: does quasiperiodic spatial organisation change the persistence of
history-readable footprints under local reinforcement and connection growth,
compared with suitable periodic and disordered substrates? (No assumption that
quasiperiodicity helps.)

## Headline recommendation

Use **rhombus tilings** (every face has 4 bounding edges and 2 diagonals, so the
v1–v8 face rule transfers verbatim), all generated by **one de Bruijn multigrid** so
the arms share a mechanism and a tile set. Minimal informative core: **Penrose
(quasiperiodic) vs jittered-pentagrid (disordered)**; add a **Fibonacci-approximant
periodic** arm iff its construction passes validation within budget. Fair reader:
a **frozen proximity-sign one-bit contrast** with the **Fixed model as an automatic,
symmetry-free no-memory baseline**. Report memory against both wall-clock and a
**saturation coordinate** to separate slower saturation from stronger retention.
Engine dynamics reuse v2 unchanged; only construction, the growth-trigger face
lookup, and the reader sign need generalising. Estimated dynamics runtime ≈ 10–20
min; the real cost is construction + validation. No E8 dependency.
