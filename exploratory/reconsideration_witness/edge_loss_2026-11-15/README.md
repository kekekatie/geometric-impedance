# Distance-3 edge-loss run (2026-11-15)

Extends Astra's corrected **E_frame** baseline (`correction_2026-11-14/`, commit
`09a79c1`) to a single distance-3 **edge** loss site. Reuses her `model.py`
**unchanged** — it is report-routed, so the only scientific change is the loss site.

- **The change:** loss (1,1) → (1,2). The edge star is 3 checks (Z-stab 2, X-stabs 3,6),
  so the local diamond query drops from 8 readings to **6**. (1,2) is outside both logical
  supports, so the scored `Z_L` convention is unchanged.
- **Carried forward:** XOR parity, Bernoulli-odds weights, ε-ties, the report-blind 2-bit
  committed frame, shared-onset inference, four arms, site-agnostic archive, cold
  fresh-process restart, honest accounting.

## Headline result

Moving to the edge makes the local diamond **weaker**: diamond/reference disagreements
rise **341 → 896** (≈2.6×) despite the smaller query — the reduced neighbourhood captures
less, so the smaller query is a real information reduction, not a free saving. Whole ==
thick still holds exactly; ~⅓ of diamond disagreements are the diamond being right and the
reference wrong. See `HANDBACK_EDGE.md` for the full bulk-vs-edge table and accounting.
