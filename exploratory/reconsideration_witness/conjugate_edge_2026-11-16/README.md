E_frame model (`correction_2026-11-14/`) unchanged. Holds bracket size fixed (6 lip
bits, like the Z-open site (1,2)) while opening the conjugate sector.

  readings, X-arms = onset-sector readings**.

- (2,1) X-open: 2 Z-arms + 1 X-arm → **837** disagreements.

## Headline

**The conjecture is refuted: keeping both Z-arms does not restore bulk-like accuracy.**
Both 3-check edges (837, 896) are far above the 4-check bulk (341), so **bracket size
drives the degradation, not which sector's check is lost**. The small sector asymmetry is
metric-dependent (X-open better by raw count, worse by weighted agreement). See the 3-way
table in `HANDBACK_CONJUGATE.md`.
